CONTACT & SUPPORT

Questions, bugs or ideas?

PanoPath is an open-source personal project. The best contact route depends on whether the discussion is about the software or its creator.

Software issues

For reproducible bugs, browser compatibility problems, feature requests or export failures, use the PanoPath GitHub issue tracker. Include the browser name and version, operating system, source panorama dimensions, chosen output dimensions and frame rate. Do not attach a private panorama; a generated or non-sensitive sample that reproduces the problem is preferable.

Security and privacy

If the report contains sensitive security information, avoid publishing exploit details or personal media in a public issue. Contact the creator through the options listed on Prabal Banerjee’s personal contact page. That page contains the current public channels and identity links.

Source and attribution

The complete browser implementation is available in the public source repository. PanoPath is maintained by Prabal Banerjee. There is currently no commercial support program, guaranteed response time, account-support desk or telephone support service.

Before reporting an export issue

Try Chrome or Edge, reduce the output to 1080p at 30 fps, and verify that the source image is a valid 2:1 equirectangular panorama. Very large 4K or 60 fps exports require substantial graphics memory and may take longer even though their timeline remains frame-locked.
